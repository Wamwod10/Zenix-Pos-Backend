# Product promotion rollout contract
Pure same-SKU whole-unit evaluation only. No changes to live sale pricing or receipt data.
Proposed first phase: opt-in 2+1 / 3+1 and quantity-percent offers, organization-owned and optionally branch-limited, UTC start-inclusive/end-exclusive, deterministic single best discount per product, no combination with manual discounts, packaging, fractional/weighted items or other coupons. No global automatic activation.
Before live rollout: persist owner-authored rules with audit/revision, calculate from locked authoritative catalog and merged product quantities in sale transaction, require quote/version reconciliation, allocate exact line cents for partial returns (including free-item allocation policy), enforce cashier/owner permissions, reflect actual net on POS/receipts/P&L and notifications. Test concurrent rule changes, replay, inventory, returns and branch/tenant isolation. Do not accept client-supplied discount as promotion authority.
